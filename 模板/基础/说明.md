# __TITLE__

这是一个 DSH 预设。由「预设工作室」从模板生成，接线已经接好，你只需要填内容。

## 怎么填

| 位置 | 填什么 |
|---|---|
| `注入\10-人设.md` | 它是谁、按什么流程干活。这一段常驻系统提示词，最重要。 |
| `注入\20-风格.md` | 语感。填完再把开关打开（默认关）。 |
| `注入\30-纪律.md` | 允许什么、禁止什么。填完再开。 |
| `注入\70-模式.md` | 可整块开关的流程。填完再开。 |
| `文档\设定.md` | 人物、地点、既定事实。模型会按需翻开，也能自己往里写。 |
| `技能\example\SKILL.md` | 一类活的具体做法。改完再打开（示例默认关）。 |

序号按段位排：10 人设 / 20 风格 / 30 纪律 / 50 字数 / 70 模式 / 90 补丁。
数字留空位，以后插新的不用重排。

## 装进 DSH

面板右上角「装进 DSH」。装完之后在聊天界面选它，**开新对话**才读得到最新内容。

## 改了东西不生效

- 注入、文档、技能：改完下一轮就生效（投递器会重读文件）。
- `cordis.patch.yml` 里加的插件行：要开新对话，预设才重新挂载。
