# 模板：基础

这个目录是「预设工作室」新建预设时复制的东西。**改这里，以后新建的每一个预设都会跟着变。**

## 里面每一格是干什么的

| 文件 | 作用 | 模型什么时候能看到 |
|---|---|---|
| `cordis.patch.yml` | 这个预设的全部接线：人设、技能目录、投递器、写回工具 | 不看到，这是配置 |
| `package.json` | 包名与版本，DSH 靠它认出「这是一个预设」 | 不看到 |
| `注入\10-人设.md` | 你是谁、怎么干活 | 常驻系统提示词（默认开） |
| `注入\20-风格.md` | 语感、写什么不写什么 | 常驻（默认关，填完再开） |
| `注入\30-纪律.md` | 允许什么、禁止什么 | 常驻（默认关） |
| `注入\70-模式.md` | 可整块开关的流程 | 常驻（默认关） |
| `文档\设定.md` | 人物、地点、既定事实 | 按需翻开；模型也能自己往里写 |
| `技能\example\SKILL.md` | 一类活的具体做法 | 按需打开（示例默认关） |

## 占位符（新建时会被替换，别手动改成别的写法）

| 占位符 | 替换成 |
|---|---|
| `__TITLE__` | 你在面板里填的显示名 |
| `__PRESET_ID__` | 预设 id（小写英文），同时用作 patch 里的 `id` 和 `config.id` |
| `__PACKAGE__` | `@local/dsh-preset-<id>` |
| `__DIR__` | 新预设的绝对路径（所以模板里不能写死路径） |
| `__PERSONA__` | 由显示名生成的一句人设前缀 |

## 序号段位（新建注入时按这个排）

| 段位 | 放什么 |
|---|---|
| 10–19 | 人设、输出协议 |
| 20–29 | 风格、人称 |
| 30–49 | 纪律、边界 |
| 50–69 | 字数、节奏 |
| 70–89 | 模式（互斥的几套流程放不同号） |
| 90+ | 临时补丁、格式清洗 |

数字不用连续，留空位是为了以后能插进来，不用重排。

## 新建出来的预设长什么样

- 接线是**预先接好的**：技能目录、投递器、写回工具都在 patch 里，面板上不该出现「未接上」。
- 工具只有两个：读技能（`tool-skill`）和写回文档（`studio-docs`）。要读写文件、跑终端，在面板「工具」里加。
- 关了 `includeDefaultRoots`：这个预设的技能目录里只会有你自己的技能和文档，不会混进 DSH 自带的开发技能。
